# Changelog

Notable changes to this project. The format follows

## [0.1.0] - 2026-08-03

- Initial release: async ICMP/TCP/HTTP/DNS probes, flap-resistant alerting
  with a state machine, SLO and error-budget tracking, latency percentiles,
  Prometheus metrics and an SSE live dashboard on a single-process SQLite
